# A/B-тест рекомендательного алгоритма развлекательного приложения

## О проекте

Команда разработчиков развлекательного приложения с бесконечной лентой контента создала новый алгоритм рекомендаций. Предполагается, что он позволит показывать пользователям более интересный контент и повысит их вовлечённость.

**Цель проекта** — спланировать A/B-тест, проверить корректность его проведения и оценить, приводит ли новый алгоритм к увеличению доли успешных первых сессий.

Успешной считается первая сессия, в ходе которой пользователь просмотрел **четыре и более страниц**.

## Задачи

В рамках проекта:

- проведён исследовательский анализ исторических данных о регистрациях, просмотрах страниц и первых сессиях пользователей;
- исследована динамика доли успешных первых сессий;
- рассчитаны необходимый размер выборки и предполагаемая длительность A/B-теста;
- проверена корректность распределения пользователей между экспериментальными группами;
- проверено отсутствие пересечений пользователей между группами;
- сопоставлены распределения пользователей по устройствам и регионам;
- сформулированы статистические гипотезы и определена целевая метрика;
- проведён z-тест пропорций для сравнения экспериментальных групп;
- сформулированы выводы и рекомендации по внедрению нового алгоритма.

## Данные

Использованы исторические данные о пользовательской активности в приложении и результаты A/B-эксперимента.

Данные содержат информацию о пользователях, регистрациях, просмотрах страниц, первых сессиях, экспериментальных группах, устройствах и регионах.

## Инструменты

**Python · pandas · NumPy · SciPy · statsmodels · Matplotlib · Jupyter Notebook**

В работе использованы методы исследовательского анализа данных, визуализации, расчёта параметров эксперимента и статистической проверки гипотез.

## Планирование эксперимента

В качестве целевой метрики выбрана доля пользователей, просмотревших четыре и более страниц во время первой сессии.

По результатам предварительного анализа рассчитаны параметры эксперимента:

- **Необходимый размер выборки:** 41 040 пользователей в каждой группе.
- **Общий размер выборки:** не менее 82 080 пользователей.
- **Расчётная длительность:** 9 дней при среднем ежедневном трафике около 9 907 пользователей.

Перед анализом результатов проведена проверка качества эксперимента. Размеры групп практически совпадают, пересечения пользователей отсутствуют, распределения по устройствам и регионам сопоставимы.

## Результаты A/B-теста

Основная метрика — доля успешных первых сессий.

| Показатель | Группа A | Группа B |
|---|---:|---:|
| Доля успешных первых сессий | 31,57% | 31,47% |

Относительное различие между группами составило около −0,33%.

Для проверки гипотезы об увеличении доли успешных первых сессий использован односторонний z-тест пропорций.

- **Уровень значимости:** 0,05.
- **p-value:** 0,58.

Полученное значение p-value превышает уровень значимости, поэтому оснований отвергнуть нулевую гипотезу нет.

**Статистически значимого улучшения целевой метрики при использовании нового алгоритма не обнаружено.**

## Вывод

Эксперимент не подтвердил гипотезу о положительном влиянии нового рекомендательного алгоритма на вовлечённость пользователей.

На основании полученных результатов **не рекомендуется внедрять новый алгоритм для всех пользователей** без дополнительной проверки и доработки.
